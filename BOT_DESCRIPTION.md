# 🍞 Bánh Mì Bot - All-in-One Discord Bot

> Powerful, feature-rich Discord bot with moderation, music, leveling, economy, and social media integration. Built for Vietnamese communities but supports multiple languages.

## ✨ Key Features

### 🛡️ **Advanced Security & Moderation**
- **Anti-Raid Protection**: Automatically detects and prevents raid attacks
- **Anti-Spam System**: Smart spam detection with customizable thresholds
- **Moderation Commands**: Ban, kick, mute, timeout, warn with detailed logging
- **Channel Management**: Lock, unlock, slowmode, purge messages
- **Auto-Moderation**: AI-powered content filtering

### 🎵 **Premium Music Player**
- **Multi-Platform Support**: YouTube, Spotify, SoundCloud
- **High Quality Audio**: 320kbps streaming, no lag
- **Advanced Controls**: Play, pause, skip, stop, loop, shuffle
- **Queue Management**: View and manage song queue
- **Interactive Controls**: Beautiful embeds with reaction buttons

### 🏆 **Level & Economy System**
- **Auto XP System**: Members earn XP for activity
- **Custom Rank Cards**: Beautiful, personalized rank cards
- **Leaderboards**: Server-wide rankings
- **Economy System**: Virtual currency, shop, mini-games
- **Level Roles**: Auto-assign roles based on level

### 🔗 **Social Media Link Fixer** (Like Bot Keto!)
- **TikTok**: Auto-download and repost videos without watermark
- **Twitter/X**: Fix embeds for better previews
- **Instagram**: Direct video/image embeds
- **Reddit**: Enhanced post previews
- **Custom Embeds**: Beautiful black embeds with stats and buttons

### 📊 **Server Management**
- **Welcome System**: Customizable welcome messages
- **Auto-Roles**: Assign roles to new members
- **Ticket System**: Support ticket with transcripts
- **Verification**: Captcha/button verification
- **Voice Logs**: Track voice channel activity

### 🎮 **Fun & Entertainment**
- **Mini-Games**: 8ball, dice, coinflip, RPS
- **Meme Commands**: Vietnamese meme generator
- **Avatar**: View user avatars
- **Server Info**: Detailed server statistics

## 🚀 Quick Setup

1. **Invite the bot** to your server
2. Run `/setup` for guided setup wizard
3. Grant Administrator permissions (or minimum required perms)
4. Done! Bot is ready to use

### Quick Commands
```
/help       - View all commands
/setup      - Setup wizard for new servers
/stats      - Bot statistics
/invite     - Invite bot to another server
/play       - Play music
/antiraid   - Enable raid protection
/linkpreview - Enable social media link fixing
```
