# Privacy Policy - Bánh Mì Bot

**Effective Date:** January 14, 2025  
**Last Updated:** January 14, 2025

## 1. Introduction

This Privacy Policy describes how Bánh Mì Bot ("we", "our", "the Bot") collects, uses, and protects your information when you use our Discord bot.

## 2. Information We Collect

### 2.1 Automatically Collected Information
- **Server ID:** To identify which Discord server the Bot is operating in
- **Channel IDs:** To manage channel-specific configurations
- **User IDs:** For level tracking, moderation logs, and command usage
- **Message Metadata:** Timestamps, reaction counts (no message content stored)

### 2.2 Command Usage Data
- **Command Name:** Which command was used
- **Timestamp:** When the command was executed
- **User ID:** Who executed the command
- **Server ID:** Where the command was executed

### 2.3 Temporary Data Processing
- **Message Content:** Temporarily scanned to detect TikTok/social media links
  - **Not stored permanently**
  - **Deleted immediately after processing**
  - **Only used for link detection**

### 2.4 Configuration Data
- **Server Settings:** Link preview preferences, moderation settings
- **Role IDs:** For level rewards and permission management
- **Channel Lists:** Allowed/blocked channels for features

## 3. How We Use Your Information

We use collected information to:
- **Provide Bot Functionality:** Enable link fixing, moderation, music playback
- **Improve Services:** Analyze usage patterns to enhance features
- **Maintain Security:** Detect and prevent abuse or violations
- **Store Configurations:** Remember server-specific settings

## 4. Data Storage and Security

### 4.1 Storage Location
- Data is stored locally in JSON files on our server
- No third-party database services used
- Files are backed up regularly

### 4.2 Security Measures
- Access restricted to Bot administrators only
- Server secured with industry-standard practices
- Regular security audits and updates

### 4.3 Data Retention
- **Server Configs:** Retained while Bot is in your server
- **Level Data:** Retained indefinitely unless requested for deletion
- **Temporary Data:** Deleted within seconds of processing

## 5. Third-Party Services

The Bot uses the following third-party services:

### 5.1 TikWM API (https://tikwm.com)
- Used to download TikTok videos without watermark
- Your TikTok links are sent to their API
- Subject to their Privacy Policy

### 5.2 Discord API
- All Bot operations use Discord's official API
- Subject to Discord's Privacy Policy and Terms of Service

### 5.3 YouTube API (Music Feature)
- Used to search and stream music
- Subject to YouTube's Terms of Service
