Hệ thống Economy

Banhcuon Bot có hệ thống kinh tế dual currency với role-based bonuses

/daily Free

Nhận phần thưởng hàng ngày. Bonus dựa trên role trong server:

  • 🏪 Chủ Tiệm: +1000 Blue + 50 Gold
  • 🌯 Bánh Cuốn Chúa: +800 Blue + 40 Gold
  • 🔥 Hành Phi Elite: +600 Blue + 30 Gold
  • 💎 Default: +100 Blue Coins
/balance Free

Xem số dư Blue Coins và Gold Coins của bạn, kèm streak và thống kê check-in

/convert Free

Đổi Blue Coins sang Gold Coins hoặc ngược lại với tỷ giá động

All Commands

Danh sách đầy đủ các lệnh slash commands

💰 Economy

/daily - Nhận phần thưởng hàng ngày
/balance - Xem số dư coins
/convert - Đổi Blue ↔ Gold Coins
/shop - Xem và mua items

👨‍💼 Admin

/coins add - Thêm coins cho user
/coins remove - Trừ coins của user
/coins set - Set coins cho user

🛠️ Utility

/help - Hiển thị hướng dẫn
/ping - Kiểm tra ping
🔌

REST API

Dashboard API endpoints cho web integration

GET
/api/shop/items

Lấy danh sách tất cả items trong shop với stock info

GET
/api/user/:userId/coins

Lấy balance của user (blueCoins + goldCoins)

POST
/api/shop/purchase

Mua item từ shop (cần userId, itemId)

GET
/api/bot/status

Lấy status của bot (online, ping, guilds, users)

Example Response:

{
  "success": true,
  "blueCoins": 450,
  "goldCoins": 12,
  "coins": 450
}

❓ FAQ

Câu hỏi thường gặp

Banhcuon-bot có miễn phí không?

Hoàn toàn miễn phí! Tất cả tính năng cốt lõi đều free. Premium chỉ là tùy chọn để có thêm perks.

Làm sao thêm bot vào server?

Click invite link, chọn server của bạn, cấp quyền và bot sẽ hoạt động ngay lập tức.

Bot có hỗ trợ tiếng Việt không?

Có! Bot được thiết kế 100% cho cộng đồng Việt Nam với UI và commands tiếng Việt.

Làm sao kiếm Blue Coins?

Dùng /daily mỗi ngày, hoàn thành quests (gửi tin nhắn, dùng commands), bonus theo role trong server.

Gold Coins dùng để làm gì?

Gold Coins có giá trị cao hơn Blue Coins, có thể đổi qua lại với tỷ giá linh hoạt.

Premium có giá bao nhiêu?

Coming soon! Dự kiến 50K/tháng với nhiều tính năng độc quyền và priority support.
